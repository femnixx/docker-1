201~200~# Multi-Container Web Architecture with Reverse Proxy & Secure Tunneling

A production-grade, stateful web architecture deployed on a Debian server. This project demonstrates modern infrastructure practices, utilizing Docker Compose for microservice isolation, Caddy as an edge reverse proxy, and Tailscale Funnel for public ingress routing without exposing the host to public-facing firewalls.

## 🏗️ System Architecture

```text
[ Public Client ]
       │ (Encrypted HTTPS Request)
              ▼
              [ Tailscale Edge Relays ]
                     │ (WireGuard VPN Tunnel)
                            ▼
                            [ Debian Host Server ] ───► Listens via Tailscale Daemon (Port 3000)
                                   │ (Host Network Adapter Handoff)
                                          ▼
                                          [ Docker Bridge Network ] ──► Maps Host Port 3000 to Container Port 80
                                                 │
                                                        ▼
                                                        [ Caddy Proxy Container ] ──► Routes Request based on Caddyfile
                                                               ├── /        ──► Serves Static Frontend (index.html via mounted volume)
                                                                      └── /upload  ──► Reverse Proxies to Express API (Port 5000)
                                                                                                   │
                                                                                                                                ▼
                                                                                                                                                     [ Express API Container ] ──► Stores file persistently
                                                                                                                                                                                                            │
                                                                                                                                                                                                                                                                   ▼
                                                                                                                                                                                                                                                                                                                [ Named Docker Volume ]
                                                                                                                                                                                                                                                                                                                ```

                                                                                                                                                                                                                                                                                                                ## ⚙️ Core Components

                                                                                                                                                                                                                                                                                                                *   **Host OS:** Debian Linux
                                                                                                                                                                                                                                                                                                                *   **Ingress & Tunneling:** Tailscale Funnel (Public HTTPS Gateway)
                                                                                                                                                                                                                                                                                                                *   **Edge Router / Web Server:** Caddy (Containerized v2)
                                                                                                                                                                                                                                                                                                                *   **Backend Application Engine:** Node.js / Express (Containerized)
                                                                                                                                                                                                                                                                                                                *   **Persistent Storage Engine:** Managed Named Docker Volumes

                                                                                                                                                                                                                                                                                                                ## 🚀 Key Infrastructure Patterns Implemented

                                                                                                                                                                                                                                                                                                                1.  **Network Segmentation:** The backend Express API runs inside an isolated Docker bridge network. It does not expose any host ports, shielding it from external vector threats. All public requests must safely navigate through Caddy.
                                                                                                                                                                                                                                                                                                                2.  **Reverse Proxying:** Caddy maps paths dynamically, handling static frontend distribution at `/` while proxying complex data endpoints like `/upload` to separate containers.
                                                                                                                                                                                                                                                                                                                3.  **Stateful Decoupling:** Implemented an independent, named Docker volume (`storage_data`). This ensures file integrity; uploaded artifacts persist seamlessly across container recreation, software crashes, or infrastructure teardowns.
                                                                                                                                                                                                                                                                                                                4.  **Zero-Firewall Ingress:** Leveraged Tailscale Funnel to safely securely pipeline external web requests over a point-to-point WireGuard mesh tunnel, keeping host system router ports tightly closed.

                                                                                                                                                                                                                                                                                                                ### `Caddyfile`
                                                                                                                                                                                                                                                                                                                ```caddy
                                                                                                                                                                                                                                                                                                                http://:80 {
                                                                                                                                                                                                                                                                                                                	    # Reverse proxy API requests to the isolated Express backend
                                                                                                                                                                                                                                                                                                                	        reverse_proxy /upload api:5000

                                                                                                                                                                                                                                                                                                                	            # Serve static assets
                                                                                                                                                                                                                                                                                                                	                root * /srv/test-file
                                                                                                                                                                                                                                                                                                                	                    file_server
                                                                                                                                                                                                                                                                                                                	                    }
                                                                                                                                                                                                                                                                                                                	                    ```
